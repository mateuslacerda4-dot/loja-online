# TechStore - Loja Online

Página web de uma loja online desenvolvida em HTML, CSS e JavaScript.

## Descrição

Projeto educativo que demonstra a criação progressiva de uma página web através de commits incrementais.

## Funcionalidades

- Cabeçalho com nome da loja e menu de navegação
- Secção de produtos com 3 artigos
- Estilos CSS modernos e responsivos
- Rodapé
- Funcionalidade de carrinho de compras (contador com JavaScript)

## Como visualizar

Abra o ficheiro `index.html` num navegador ou aceda à página através do GitHub Pages (se ativado).

## Histórico de commits

O projeto foi construído de forma progressiva com vários commits documentados.
